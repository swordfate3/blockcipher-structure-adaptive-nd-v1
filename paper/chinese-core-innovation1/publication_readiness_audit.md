# 中文核心论文投稿就绪审计

## 1. 论文定位与核心主张

本文拟回答的不是“是否构造了一个通吃所有 SPN 的统一网络”，也不是“是否突破了 uKNIT 或 Dialga 的公开攻击轮数”。可审稿的研究问题为：

| 研究问题 | 正文主张 | 必要证据 |
|---|---|---|
| RQ1 | 在冻结的 uKNIT-BC r5 协议下，结构专家相对代表性公开网络架构是否具有同数据优势 | K1-CA/K1-CB 五模型、双 seed、同四份缓存、同训练预算主表 |
| RQ2 | 观察到的优势是否依赖正确 S 盒语义或正确 GF(2) 拓扑 | uKNIT K1-U；Dialga D1/DMC2 的正确、错误/扰动及无结构控制 |
| RQ3 | 运行时结构说明书是否在推理阶段被模型实际消费 | Dialga D2 同一冻结检查点，仅替换说明书 |
| RQ4 | 成功窗口能否机械扩展到相邻轮数 | uKNIT K1-BV r6；Dialga D3 prefix-r5 的完整失败边界 |

允许的核心结论是：机器可读结构说明书配合机制相关的差异化专家，可在 uKNIT-BC r5 与 Dialga-128 prefix-r4 的冻结协议中形成可归因的神经区分优势。结论只覆盖这两个公开算法、指定约化轮数、差分、负样本和验证协议。

## 2. 外部验收依据

当前尚未确定目标期刊，因此本文按密码学/计算机类中文核心通用标准验收，具体篇幅、模板和声明格式待选刊后适配。

1. 《软件学报》官方投稿指南要求充分讨论并比较国内外同类工作，明确标引他人成果；新算法的优越性必须由数学证明或实验对比支撑。该指南仅作为计算机类中文核心的一手通用校准，不冒充《密码学报》或其他期刊的具体规定。
2. 神经差分密码分析综述要求区分训练、验证和 fresh test，报告各数据集规模，在多份 fresh test 上给出误差范围，并报告参数量、FLOPs、训练时间、硬件及开放复现材料。
3. Gohr、Leander 和 Neumann 的评估指出，把神经网络迁移到新密码时至少应小范围检查学习率、L2 正则和卷积核尺寸。因此“统一预算”不等于“每个基线均达到各自最优”。
4. Gohr 2019 和 AutoND/DBitNet 的公开协议采用远大于本文的训练/验证集，并含独立测试。本文的 `262144/class` 是项目论文上限，不是这些工作的精确 paper-scale 复现。

详细来源、原文定位和文献元数据见 `sources/research_chinese_core_publication_and_nd_reporting_20260803.md`。

## 6. 非阻断但必须披露的改进项

- 没有独立 fresh final test；现有 AUC 来自冻结跨密钥验证集，且该验证集用于训练监控或检查点选择。
- 只有两个随机种子，不能据此进行可靠的显著性检验或方差估计；正文只报告逐 seed、均值/范围和方向一致性。
- 各公开网络采用统一数据与优化预算，但未进行充分的逐模型超参数搜索；比较回答“统一协议下架构适配表现”，不回答“各模型最优能力”。
- 模型参数量不匹配，且统一 FLOPs、训练时间、推理吞吐和显存表尚未形成。
- K1-U、K1-CA、K1-CB、K1-BV、DMC1、DMC2 的归档来源等级不同，需保留本地闭环、fallback 原始回收、远程 gate 等状态区分。
- uKNIT K1-BZ 为 `2048/class` 先导诊断，不能替代 K1-CA/K1-CB 主结果。

这些限制会降低结论强度，但在论文主张已经收窄到结构归因且主表完成的前提下，不自动触发新的大规模训练。

## 7. 明确不再开展的实验

- 百万级训练或把 `10^7` 公开协议机械复制到本文两种密码；
- 第三个或更多 seed、五次 fresh test 作为当前投稿前置条件；
- 新增网络族、新轮数、新密码、related-key、GPD、RX、polytope 或其他攻击路线；
- 为每个基线开启大规模超参数搜索矩阵；
- 对 K1-BV/D3 的失败结果继续机械扩 pair 或扩样；
- 任何不能改变 RQ1-RQ4 中具体一条正文主张的训练。

新增实验只有在外部审稿意见明确指出某个现有证据槽不足、且结果会改变正文主张时，才重新立项。
