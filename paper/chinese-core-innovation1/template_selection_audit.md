# 《计算机学报》官方 LaTeX 模板选择与兼容性审计

## 1. 目标与结论

中文核心期刊不存在跨刊通用的 LaTeX 投稿模板，版式必须由目标期刊决定。本稿研究主题属于计算机与信息安全方向，因此当前投稿对象按《计算机学报》处理；该刊官网同时提供可核验的 LaTeX 包和投稿指南，适合作为本轮排版基准。若后续改投《软件学报》《计算机研究与发展》等期刊，须重新下载目标期刊当时有效的模板并单独改版，不能把本兼容类直接冒充其他期刊模板。

本投稿版以《计算机学报》官网当前投稿页面提供的 `LatexTemplet.zip` 为版式依据。官网同时提供 Word 模板、LaTeX 模板、征稿指南和投稿声明。由于官方 LaTeX 包仍采用 GBK/CJK 与较旧的 pdfLaTeX/MiKTeX 字体链，本项目没有直接改写或冒称其为“官方新版”，而是建立 UTF-8/XeLaTeX 兼容类：保留官方 A4 版心、10.5 bp 左右正文字号、双栏、8 mm 栏距、首页中英文信息组织和图表规范，替换旧编码与不可复现字体依赖。

官方压缩包包含 `CjC.cls`、`CjC_template_tex.tex`、示例 PDF 及若干旧式宏包。官网仍在提供该包，但主要文件时间为 2018 年，`CjC.cls` 标记为 2019 版。

## 3. 复现的版式参数

官方 `CjC.cls` 的关键参数为：A4、10.5 pt、双栏、双面；页面左右总留白约 38 mm、上下总留白约 62 mm；栏间距 8 mm；正文行距倍率约 1.14。兼容类 `templates/cjc-utf8.cls` 按这些参数设置版心与正文，并使用本机和常见 TeX Live 环境可获得的 Noto CJK 与 TeX Gyre 字体。

## 4. 投稿要素核对

投稿版首页包含中文题名、作者和单位占位、中文摘要、5--7 个中文关键词、中图分类号、英文题名、英文作者和单位占位、英文摘要及英文关键词。作者姓名、单位、邮编、邮箱、电话、基金和收稿日期不得编造，均保留明显占位；DOI 按官网示例标明“投稿时不提供”。正文使用双栏；相关工作与引言分离；图表在首次讨论附近出现；参考文献按正文引用顺序排列；末页包含英文研究背景和作者简介占位。

## 5. 使用边界

`cjc-utf8.cls` 是“依据官网官方模板制作的项目兼容版”，不是《计算机学报》发布或认证的新模板。正式投稿前应再次核对目标期刊官网，填写真实作者信息，并按编辑部届时要求决定提交官方 Word 模板、官方旧 LaTeX 包，或本兼容版生成的 PDF/源文件。
