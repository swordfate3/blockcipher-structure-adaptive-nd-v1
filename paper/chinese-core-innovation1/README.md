# 中文核心论文工程：创新一结构先验神经区分

**暂定题目：**《面向非轮对齐异构 SPN 的运行时结构先验神经区分方法》

## 当前定位

本文不是“攻击轮数突破”论文，也不是“一个统一网络自动通吃所有 SPN”的论文。当前最稳妥定位是：

> 面向 uKNIT-BC 与 Dialga-128 两类异构 SPN，构建统一的运行时结构描述接口，并根据结构特征组合差异化神经专家，验证结构先验在约化轮神经区分任务中的作用与边界。

## 当前证据状态

- **可开始写初稿：是。** 方法、结构分析、实验协议、结果框架、局限性均可先写。
- **可直接投稿定稿：否。** uKNIT K1-BT 已因 run-id 冲突与缓存契约失败判为协议无效；K1-BS/K1-BZ 只有小样本本地证据，Dialga DMC1 的归档仍需闭环，正式论文规模证据不足。
- **论文边界：** 当前支持“结构描述 + 差异化专家 + 控制实验协议”，不支持“自动识别任意 SPN 并生成最优网络”。
