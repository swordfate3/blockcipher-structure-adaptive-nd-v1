# 中文核心论文工程：创新一结构先验神经区分

**暂定题目：**《面向异构 SPN 的运行时结构先验神经区分方法：Dialga 拓扑归因与 uKNIT 非线性语义验证》

## 当前定位

本文不是“攻击轮数突破”论文，也不是“一个统一网络自动通吃所有 SPN”的论文。当前最稳妥定位是：

> 面向 uKNIT-BC 与 Dialga-128 两类异构 SPN，构建统一的运行时结构描述接口，并根据结构特征组合差异化神经专家，验证结构先验在约化轮神经区分任务中的作用与边界。

## 当前证据状态

- **完整初稿：已形成。** `codex_manuscript.md` 已纳入 uKNIT K1-U、Dialga D1/D2/DMC1/DMC2、公开架构适配对比和失败边界。
- **当前实验上限：262144/class。** DMC2 是本文最高规模的双 seed Dialga 结果；百万规模 DFC1 已按作者决定终止，1/6 行局部产物不进入论文结论。
- **可直接投稿定稿：否。** 仍需逐条核验参考文献、作者与基金信息，并按目标期刊模板排版；K1-U/DMC2 的原始回收来源、DMC2 无独立最终测试等限制必须保留。
- **论文边界：** 当前支持“结构描述 + 差异化专家 + 控制实验协议”，不支持“自动识别任意 SPN 并生成最优网络”。
