六种SPN加密架构速查表

复习时只看操作顺序、状态布局和最关键的结构差异。箭头左到右表示真实项目实现中的执行顺序。

密钥/常数/tweak S盒 线性扩散

PRESENT-80

AddRoundKey → 16×S-box → 64-bit P-layer → 更新80-bit密钥；31轮后再AddRoundKey

状态：16个连续4-bit nibble。记忆点：完整轮密钥先加，P-layer是一对一bit接线。

GIFT-64

16×S-box → PermBits → 稀疏AddRoundKey → AddConstant → 更新128-bit密钥；共28轮

状态：16个连续4-bit nibble。记忆点：先S盒再加密钥；密钥只注入每个nibble的两个bit角色。

SKINNY-64/64

SubCells → AddConstants → AddRoundTweakey(前两行) → ShiftRows → MixColumns；共32轮

状态：4×4个nibble。记忆点：列混合是多个cell的GF(2)异或，不是一对一置换。

RECTANGLE-80

AddRoundKey → 16×SubColumn → ShiftRows(0/1/12/13) → 更新密钥；25轮后再AddRoundKey

状态：4条16-bit行。记忆点：一个S盒竖着读取同一列的四个bit，逻辑cell在扁平数组中不连续。

uKNIT-BC

R1...R11：AddRoundKey(r) → 位置/轮相关S-box(r) → GF(2)矩阵(r)；R12：Key → S-box(12) → Key

状态：16个4-bit nibble。记忆点：12轮不是同一轮重复，每轮S盒和线性层都可能不同。

Dialga-128

初始P XOR T XOR K0 XOR K1 → 前向段 → 中间段 → 后向段 → SubCells XOR K0 XOR K1

状态：16 bytes。基本轮：SubCells → 四选一BytePerm → MixColumns。记忆点：数据和tweak双通路；完整版本为16或20数据轮。

通用网络必须读懂什么

结构字段回答的问题典型难点
cell_membership哪些bit共同进一个S盒？RECTANGLE非连续cell
bit_role某bit是cell内第几位？GIFT稀疏密钥角色
sbox_tables局部非线性函数是什么？uKNIT按轮/位置变化
linear_layers输出bit依赖哪些输入bit？SKINNY/Dialga多源XOR
轮序列结构是否每轮相同？uKNIT/Dialga异构调度
完整轮数与项目中的r4/r5/r6/r7前缀不是同一个概念。低轮神经结果不能表述为完整密码攻击。
