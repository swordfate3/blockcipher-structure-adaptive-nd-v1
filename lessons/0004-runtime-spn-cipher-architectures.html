六种SPN密码到底怎样加密

把 PRESENT、GIFT、SKINNY、RECTANGLE、uKNIT 和 Dialga 放在同一张地图上：先看状态怎样摆，再看一轮怎样走，最后理解为什么“运行时读取密码结构”的神经网络比单密码网络难得多。

先记一句话：SPN 都在反复做“局部非线性变换 + 全局扩散 + 密钥注入”，但六种算法的 cell 划分、操作顺序、扩散方式和轮间变化并不相同。项目中的低轮实验只是截取完整加密流程的前缀，不等于攻击完整轮密码。

1. 先用一个小数据例子理解SPN

假设一个玩具状态只有四个4-bit小块，写成十六进制就是：

输入状态0 1 2 3
→
PRESENT S盒C 5 6 B
→
扩散层把16个输出bit重新接线

S盒像16本小字典：输入0查到C，输入1查到5。它负责制造非线性。扩散层再把每个小块的4个输出bit送往不同位置，使一个局部变化在后续轮传播到更大范围。

“扩散”不总是简单搬家。PRESENT/GIFT主要做一对一bit置换；SKINNY、uKNIT和Dialga会把多个来源bit做XOR，一个输出位置同时依赖多个输入位置。

上图只是概念骨架，不能拿来代替真实轮函数。例如 GIFT 是先做S盒和置换，再加轮密钥；SKINNY 在S盒后插入常数和tweakey；Dialga还有一条独立演化的tweak通路。

3. 六种算法逐个拆开

PRESENT：16个小盒子后做全局比特接线

状态16 × 4-bit nibble
密钥80 bit寄存器
完整轮数31轮 + 末次白化
项目研究7轮前缀
N0N1N2N3 N4N5N6N7 N8N9N10N11 N12N13N14N15

64 bit连续切成16个nibble，每个nibble独立查同一张4-bit S盒。

P-layer的意思

每个bit只搬到一个新位置：i → 16i mod 63，最后一位63 → 63。它不做XOR混合，但会把一个nibble的4个bit拆散到不同的下一轮S盒。

明文64-bit state
→
AddRoundKeystate XOR 80-bit寄存器高64 bit
→
16个PRESENT S盒每4 bit独立代换
→
P-layer64根bit线重新接线
→
更新80-bit密钥左旋61、最高nibble过S盒、加轮常数
以上循环31次，循环结束后再 XOR 下一轮64-bit轮密钥，输出密文

直观理解：PRESENT 像把16张四位小纸片逐张改写，然后把每张纸片剪成4条，按固定接线送给下一轮。对神经网络而言，cell边界很规则，但真正有价值的是bit级P-layer，而不是nibble编号本身。

实现依据：src/blockcipher_nd/ciphers/spn/present.py

GIFT：外形像PRESENT，但密钥只注入特定bit角色

状态16 × 4-bit nibble
密钥128 bit
完整轮数28轮
项目研究6轮
本轮输入64-bit state
→
SubCells16个GIFT S盒
→
PermBits固定64-bit一对一置换
→
AddRoundKey只注入每个nibble的bit 0和bit 1位置
→
加轮常数6个指定位置 + 固定最高位
→
更新密钥nibble重排和局部旋转
以上循环28次；与PRESENT不同，项目实现没有循环后的额外完整64-bit白化

最容易误画的地方：GIFT 不是先加密钥再进S盒。轮密钥也不是完整64 bit直接覆盖所有位置，而是抽取两组16 bit，分别注入每个nibble的两个指定bit角色。这使“密钥注入拓扑”也成为结构的一部分。

实现依据：src/blockcipher_nd/ciphers/spn/gift.py

SKINNY：4×4个cell经过行移位和列混合

状态4 × 4个nibble
密钥64-bit tweakey
完整轮数32轮
项目研究7轮
s0s1s2s3 s4s5s6s7 s8s9s10s11 s12s13s14s15
一列如何混合
out0 = s0 XOR s2 XOR s3 out1 = s0 out2 = s1 XOR s2 out3 = s0 XOR s2

这里的s0、s1、s2、s3表示同一列的四个cell。一个输出cell会依赖多个输入cell。

4×4状态16个4-bit cell
→
SubCells16个SKINNY S盒
→
AddConstants常数注入指定cell
→
AddRoundTweakey只XOR前两行8个cell
→
ShiftRows四行错位
→
MixColumns每列做多源XOR
每轮结束后置换tweakey的16个cell，再进入下一轮，共32轮

直观理解：先把每个格子改写，再把每一行错开，最后把同列的几个格子异或混合。它不能只用一张“source bit搬到target bit”的置换表表示，必须用GF(2)关系矩阵描述。

实现依据：src/blockcipher_nd/ciphers/spn/skinny.py

RECTANGLE：S盒沿列取bit，扩散却沿整行旋转

状态4条16-bit行
密钥80 bit
完整轮数25轮 + 末次白化
项目研究6轮
row 0移0
row 1左移1
row 2左移12
row 3左移13
一个S盒cell怎样取值

固定列号c，分别从四行取row0[c]、row1[c]、row2[c]、row3[c]，拼成一个4-bit输入。16列同时执行16个S盒。

因此一个逻辑cell的4个bit在普通64-bit扁平数组里并不连续。

明文4 × 16-bit rows
→
AddRoundKeyXOR轮密钥低64 bit
→
SubColumn每列跨四行组成S盒输入
→
ShiftRows四行左旋0/1/12/13
→
更新80-bit密钥列S盒、行变换、轮常数
以上循环25次，最后再 XOR 下一轮密钥低64 bit

直观理解：RECTANGLE像四条横向纸带。S盒竖着读取同一列的四个bit，随后四条纸带各自转动不同距离。网络若误把连续4 bit当成cell，就会读错整个非线性结构。

实现依据：src/blockcipher_nd/ciphers/spn/rectangle.py

前11轮中，每个输出bit由本轮表中指定的三个来源bit异或得到；但不同轮使用不同来源表。第12轮不再做线性层，而是：

state XOR RK11 → 第12轮位置相关S盒 → state XOR RK12 → 密文

密钥调度把128-bit主密钥分成两个64-bit状态：两半都经历cell内扩散和cell置换，其中第二半还先过nibble LFSR；后续轮密钥由两半异或得到。

直观理解：PRESENT像每层都用同一张接线图；uKNIT像一栋12层楼，每层不仅走廊布局不同，每个房间门锁的S盒也可能不同。这叫打破轮对齐，不能把“第1轮拓扑”复制12次。

实现依据：src/blockcipher_nd/ciphers/spn/uknit.py；规范论文：uKNIT: Breaking Round-Alignment for Cipher Design

α=4, β=3时得到16个数据轮；α=5, β=4时得到20个数据轮。每段并不是机械复制同一轮，轮型、常数、key half和tweak注入位置随调度改变。

直观理解：Dialga不是一条直线，而是两条同步运行的传送带。上面运送数据，下面运送tweak；tweak在指定位置回流到数据路径。只给网络一张静态P-layer图，会丢掉这种阶段性结构。

5. 为什么一个通用SPN神经网络很难

普通单密码网络可以把结构“焊死”在卷积核或输入排列里。例如为PRESENT写死16个nibble和一张P-layer，换成RECTANGLE后，连续4 bit已经不再是正确cell；换成SKINNY后，一对一边也表达不了列XOR；换成uKNIT或Dialga后，单张静态图又表达不了轮间变化。

当前 Runtime-E4 的目标不是让每个密码拥有一套专用主干，而是把密码本身转换成运行时结构描述：

密文对bit节点真实样本内容
+
cell_membership哪些bit共同进入一个S盒
+
S-box真值表局部非线性函数是什么
+
GF(2)关系矩阵每个输出bit依赖哪些输入bit
→
共享神经主干参数形状不随密码改变

项目现在已经能把六种算法的结构都编码进去，但“能表示”不等于“模型会正确使用”。正确拓扑必须稳定优于打乱拓扑、错误S盒和无拓扑控制，才能说明网络真的理解了结构，而不是借助某个密码的数据偏差。

6. 一分钟自测

PRESENT和GIFT都是16个nibble，它们的轮函数是否相同？

不同。S盒和P-layer不同；PRESENT先加完整64-bit轮密钥，GIFT先S盒、再置换，最后把轮密钥稀疏注入特定bit角色并加入轮常数。

为什么SKINNY不能只用一张bit permutation描述？

因为MixColumns的一个输出会异或多个输入，例如out0=s0 XOR s2 XOR s3。这不是把一个bit搬到另一个位置，而是一般GF(2)线性组合。

为什么RECTANGLE的cell边界容易标错？

它的一个4-bit S盒输入来自四条16-bit行的同一列。这4个bit在64-bit扁平表示里不连续，不能机械地每连续4 bit切成一个cell。

uKNIT和Dialga为什么叫异构轮结构？

uKNIT按轮改变S盒表和GF(2)线性矩阵；Dialga按阶段和轮型切换byte置换，并让tweak状态与数据状态双通路演化。它们都不能由“重复同一张轮图”准确表示。
