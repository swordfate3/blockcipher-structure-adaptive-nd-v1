uKNIT到底特殊在哪里

先分清两个名字：uKNIT是一种“逐轮编织密码”的设计方法，uKNIT-BC是作者用这种方法得到的64-bit分组密码。下面用一轮真实数据说明它如何加密，再解释为什么它需要专用的结构适配神经网络。

学完后的判断标准：你能解释为什么 uKNIT-BC 仍然是 SPN，却不能像 PRESENT 那样把同一张 S 盒表和同一张 P 层接线图重复多轮；也能说清当前网络为什么要读取“哪一轮、哪个 cell、哪张 S 盒、哪张 GF(2) 矩阵”。

1. 先分清：uKNIT是方法，uKNIT-BC是成品

普通迭代型 SPN 先设计一个轮函数，然后重复使用：

普通 SPN：Ri(X) = L(S(X XOR Ki))

轮密钥和常数会变，但核心的 S 与 L 通常不变。PRESENT 就像把同一个加工站复制31次。

uKNIT 把限制放开，每一轮都可以使用自己的组件：

uKNIT：Ri(X) = Li(Si(X XOR Ki))
问题普通迭代 SPNuKNIT
第1轮与第5轮的S盒通常同一张表允许完全不同
第1轮与第5轮的扩散通常同一张接线图允许完全不同
怎样设计完整密码先定轮函数，再重复一轮一轮添加并优化
自动工具的角色多用于设计后的分析直接参与候选生成与选择

“Breaking Round-Alignment”就是打破轮对齐：攻击者不能再假设每一轮都沿相同的 S 盒和扩散路径传播。注意，这不等于随机乱拼；每个候选仍要经过安全性与硬件性能评估。

2. “编织”一条密码是怎样进行的

候选池已有不超过 i 轮的多个密码
→
变异与交叉更换S盒bit转置、交换线性层行列
→
自动评估SAT搜索差分/线性轨迹，硬件流程测延迟
→
适应度排序兼顾安全、延迟和候选多样性
→
添加一轮继续编织，直到满足目标

论文中的 uKNIT-BC 搜索使用200个候选、100代遗传搜索。安全侧关注最佳差分特征概率和最佳线性轨迹偏差，性能侧用硬件实现流程测延迟。它不是“神经网络设计出的密码”，也不是“机器证明绝对安全”，而是自动搜索帮助设计者从更大的非对齐空间挑候选，最后仍需独立密码分析。

关键边界：uKNIT 的搜索工具只优化它被要求测量的目标。论文也明确指出应保存随机种子和完整配置，并让候选接受公开分析；自动化不替代密码学审查。

3. uKNIT-BC的完整骨架

分组64 bit
主密钥128 bit
总轮数12轮
组件总数12个S层 + 11个L层
64-bit状态16个4-bit cell
→
XOR Ki加入本轮64-bit子密钥
→
Si16个位置分别查本轮指定S盒
→
Li本轮专属64x64 GF(2)矩阵
上面执行11轮；每一轮的S盒布置和线性矩阵都可以不同
第11轮输出64-bit状态
→
XOR K11第12轮输入加密钥
→
S11最后一个位置相关S盒层
→
XOR K12最终白化，得到密文

因此完整 uKNIT-BC 一共有13次密钥加法：前11轮各一次，第12轮前一次，最后再白化一次。项目里的 r5 是只执行前5个“密钥 + S盒 + 线性层”的前缀，不是完整12轮攻击。

4. 一轮真实数据：每一步到底变成什么

取项目实现中的第1轮，使用全零128-bit主密钥，并令明文为：

P = 0x0123456789ABCDEF，K0 = 0
加密钥后0123456789ABCDEF
→
16个位置S盒后3DDF51B4250C281A
→
第1轮线性层后BC18D03F66A06BF0

把 S 盒前后的64 bit按16个nibble展开，可以看到每个位置单独查表：

cell位置0123456789101112131415
输入0123456789ABCDEF
输出3DDF51B4250C281A

位置相关不是一句空话。若16个输入 cell 全部都是 0，第1轮 S 盒层输出并不是16个相同值，而是：

0000000000000000 -> 39C96CC36A669536

因为同一个输入值 0 在不同位置查的表可以不同；换到第2轮，同样的全零输入又得到 995353363363AC6A。所以只把“这里有一个4-bit S盒”告诉网络远远不够，还要告诉它是哪一轮、哪个位置、哪一张真值表。

线性层不是搬家，而是三输入XOR

每个线性层都是稀疏的64x64二进制矩阵。每个输出bit恰好取三个输入bit做异或。例如对上面的 S 盒输出 3DDF51B4250C281A，第1轮线性层的低8个输出bit按项目bit编号计算为：

输出bit三个来源bit实际来源值XOR结果
y0x17, x27, x280, 0, 00
y1x16, x20, x310, 0, 00
y2x22, x26, x290, 1, 10
y3x19, x23, x241, 0, 10
y4x34, x41, x471, 0, 01
y5x33, x40, x450, 1, 01
y6x35, x42, x440, 0, 11
y7x32, x43, x460, 0, 11

于是最低字节得到 11110000，也就是十六进制 F0。第2轮会换另一张来源表，不能把第1轮的矩阵继续重复。

5. S盒不是任意乱选，线性层也不是任意乱接

uKNIT-BC 的4-bit S盒都来自 MANTIS S盒：

SMANTIS = [C,A,D,3,E,B,F,7,8,9,1,5,0,2,4,6]

不同轮、不同位置通过输入bit转置和输出bit转置得到不同版本。这样可以改变各位置的具体布尔语义，又保留低延迟实现基础。

线性层则要求每一行和每一列恰好有三个 1：每个输出依赖三个输入，每个输入也被三个输出使用。作者从 PRINCE/MIDORI 风格的低延迟矩阵出发，通过受约束的行列交换产生候选，所以结构在变，但稀疏度、可逆性和硬件深度受到控制。

6. 128-bit主密钥怎样变成13个轮密钥

先把主密钥拆成两个64-bit半部。前两个轮密钥直接使用这两个半部；从 K2 开始，两条支路分别更新后再异或：

A <- P(M(A))，B <- P(M(LFSR(B)))，Ki = A XOR B
  • M：每4个nibble做一次轻量异或扩散。
  • P：按固定16-nibble置换重新排位置。
  • LFSR：只作用于第二条支路的每个nibble。
  • XOR：两条已扩散的64-bit状态合成为后续轮密钥。

例如主密钥 0123456789ABCDEFFEDCBA9876543210 产生：

K0 = 0123456789ABCDEF
K1 = FEDCBA9876543210
K2 = 57985450E5C15A3D
K3 = 9C147013EEBA0EE6
K4 = E996F9EB0D9A5B98
K5 = 13C665B68B5607C6

7. 为什么它不该和Midori、Dialga硬共用一个最优网络

算法真正主导的结构对网络的要求
uKNIT-BC每轮/每位置S盒变化，11张不同GF(2)线性矩阵保留轮次、阶段、cell位置、正确S盒和正确矩阵
Midori-64规则4x4 cell布局和重复的低延迟扩散骨架线性运输本身已能暴露很强信号
Dialga-128128-bit byte状态、轮型置换、MixColumns和tweak路径需要byte/tweak语义；当前低轮任务的线性锚点已近饱和

三者都可以叫 SPN，但“都是 SPN”只相当于“都是交通工具”，并不意味着摩托车、火车和叉车应共用一个最优控制器。历史路径名 uknit_family 只是异构 SPN 实验矩阵的工作名，不是密码学同族结论。

8. 当前uKNIT专家网络到底读取什么

当前 K1-V 不是让普通 MLP 从2048个bit里自己猜出 uKNIT。每条样本包含16对密文：

16 pair x (C的64 bit + C'的64 bit) = 2048 input bits

对 r5 前缀的最后两个结构转换，网络先按运行时描述精确构造五个阶段：

密文对ciphertext
→
逆L4inverse linear slot 1
→
逆S4inverse S-box slot 1
→
逆L3inverse linear slot 0
→
逆S3inverse S-box slot 0

每个阶段都保留16个原生cell；每个cell统计16对密文中16种nibble值出现的频率，得到：

5个阶段 x 16个位置 x 16种取值

共享的小编码器把每个16维直方图压到8维，再把 5 x 16 x 8 展平投影到128维，通过有界残差门加入主干。这样网络不用重新发明逆S盒和GF(2)运算，只学习怎样组合已经对齐的结构证据。

三个同容量控制分别问什么

  • 正确结构：使用正确的uKNIT S盒和原生cell位置。
  • 错误S盒：参数量和几何不变，只换错S盒语义；检验网络是否真依赖正确非线性层。
  • 位置抹除：使用正确S盒，但平均掉cell位置；检验原生位置是否有额外价值。

K1-V 的本地 2048/class、16-pair 诊断结果为：

seed正确结构AUC错误S盒AUC位置抹除AUC
30.9024230.5061450.591490
40.9325390.4996130.697591

这说明在该本地协议下，正确 S 盒和位置语义都提供了可重复增益；它仍只是小规模诊断，不是完整12轮攻击、正式规模或论文突破。下一步要在远程 65536/class 保持同一网络、同一16-pair数据定义和同一控制，只增加数据量。

9. 用一句话真正记住

uKNIT-BC不是“每轮重复同一种SPN”，而是“每轮都有自己S盒地图和GF(2)扩散地图的SPN”。因此适合它的网络必须沿正确轮次逆向读取这些地图；把位置和阶段全平均掉，或拿别的密码的统一共享结构强行覆盖它，都会丢失最有价值的语义。

10. 三个自测问题

为什么“uKNIT每轮不同”不等于“随便随机拼接”？

候选组件来自受约束的低延迟S盒与可逆稀疏线性层空间，并经过自动差分/线性分析、硬件延迟评估、选择、交叉和变异。最终候选还需要独立安全分析。

为什么把正确S盒换成错误S盒是关键控制？

它保持数据、参数量、网络几何、cell划分和线性层不变，只破坏非线性真值表。若正确模型稳定胜出，增益才可归因于正确S盒语义，而不只是模型更大或输入更宽。

为什么uKNIT专家网络只逆两层，而不是逆完整五轮？

当前实验改变一个受控假设：使用最后两个异构转换构造五阶段结构残差，同时保留可训练主干。它不是完整解密，也不声称已显式恢复所有五轮内部状态；更长窗口必须另做单变量实验。

主要来源：Hu 等，uKNIT: Breaking Round-Alignment for Cipher Design，特别是第2、3、5节；项目uKNIT-BC实现；位置直方图残差网络。数值例子由当前项目实现直接计算。
