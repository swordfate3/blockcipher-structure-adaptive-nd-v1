“最后两轮窗口”到底长什么样

它不是拿着轮密钥把密文真正解回两轮，而是把公开的逆线性层和逆 S 盒依次作用在密文对上，生成五个确定的观察阶段。网络或统计评分器随后比较固定差分对与独立随机明文对在这些阶段里的差分分布。

学完后的判断标准：看到 r5_exact2_position 时，你能说出五个阶段、哪些阶段的差分是准确对齐的、未知轮密钥留在哪里，以及一条 4-pair 样本怎样变成 5 x 16 x 16 = 1280 个特征。

1. 先把“最后两轮”放回完整 5 轮加密

项目的 uKNIT 5 轮前缀仍从明文完整执行五轮。若把第4轮输入记为 X3，最后两轮是：

第4轮

X3前三轮输出
→
XOR K3未知第4轮子密钥
→
S3第4轮位置相关S盒
→
L3第4轮GF(2)扩散
→
X4第4轮输出

第5轮

X4第4轮输出
→
XOR K4未知第5轮子密钥
→
S4第5轮位置相关S盒
→
L4第5轮GF(2)扩散
→
C5轮密文

代码索引从0开始，所以人说的第4、5轮在代码里是 round_start=3, runtime_rounds=2。对于6轮密文，同样的两轮窗口改成代码轮4、5，也就是人说的第5、6轮。

2. 公开窗口只撤销算子，不猜轮密钥

V0 = C密文
→
V1 = L4^-1(V0)精确撤销最后扩散
→
V2 = S4^-1(V1)得到 X4 XOR K4
→
V3 = L3^-1(V2)仍带固定密钥遮罩
→
V4 = S3^-1(V3)密钥条件化公开视图
最重要的边界：exact2 的“exact”表示使用的 S 盒表和 GF(2)矩阵与密码规范完全一致，不表示已经恢复真实内部状态。窗口没有执行 XOR K4 或 XOR K3，因为网络根本不知道这些轮密钥。

单条密文经过前两步后确实有：

V2 = S4^-1(L4^-1(C)) = X4 XOR K4

继续逆线性层时，因为 L3 是线性的：

V3 = S3(X3 XOR K3) XOR L3^-1(K4)

所以 V3 不是实际的第4轮 S 盒输出，而是它再异或一个对所有同密钥样本固定的遮罩。对密文对 C,C' 做异或时，这个固定遮罩会消掉：

Delta V3 = V3 XOR V3' = S3(X3 XOR K3) XOR S3(X3' XOR K3)

这正是窗口仍有价值的原因：虽然不知道状态本身，但多个阶段的成对差分仍能沿正确线性拓扑对齐。最后的 Delta V4 经过带未知遮罩的非线性逆 S 盒，不再等于真实更早一轮差分；它只是一个固定密钥下可重复的派生视图。

5. 为什么这些公开特征可以拿来训练

训练标签不是“某个比特是多少”，而是这条由4对密文组成的样本属于哪种生成规则：

标签明文对怎样产生网络实际拿到什么
1：真实差分P' = P XOR 0x0000400000000000只给4对5轮密文经公开窗口得到的1280维统计
0：严格负样本P 与 P' 是两个独立随机明文也先真实加密，再做完全相同的公开窗口和统计

固定差分在低轮 SPN 中沿特定 S 盒和扩散路径传播，不同 cell、不同阶段的差分值频率可能偏离独立随机对。公开窗口相当于把混在最终密文里的差分按正确结构重新摆齐，让模型不用从头猜“哪些bit在第4轮属于同一个S盒”。

可以训练，不等于一定能区分。它只是一个由密文确定、没有标签泄漏、没有明文输入、没有轮密钥输入的合法特征变换。有没有可泛化信号仍要看同预算基线、错误S盒、位置抹除、标签打乱、同密钥新样本和跨密钥验证。

最新 K1-BO 要单独说明

最新的 K1-BO 不是神经训练：它把上述1280维特征交给确定性的对角 Fisher 评分器，训练轮数、神经参数和优化步数都为0，用来先判断2轮与3轮窗口是否存在值得训练的信号。结果没有通过 AUC >= 0.55 门槛，因此当前没有授权6轮神经训练。历史 K1-U 类神经模型才会把每个16格直方图用共享的 16 -> 8 小编码器压缩，再投影为128维残差加入主干。

6. 三个自测问题

为什么不知道 K4，Delta V2 仍然是准确的第4轮输出差分？

两边在逆 S4 后分别是 X4 XOR K4 和 X4' XOR K4。再异或时，同一个 K4 出现两次而抵消，只剩 X4 XOR X4'。

为什么不能把 V4 叫作真实第3轮输出？

V3 在真实 S3 输出上还带有 L3^-1(K4) 遮罩。非线性逆 S 盒不能像线性层那样把这个遮罩简单分离，所以 V4 只是固定密钥条件下的确定视图。

一条最新 K1-BO 样本最终有多少个窗口特征？

4对密文先形成5个阶段；每个阶段保留16个cell，每个cell统计16种差分值的频率，所以是 5 x 16 x 16 = 1280。4是每格直方图的观测次数，不是额外的特征维。
