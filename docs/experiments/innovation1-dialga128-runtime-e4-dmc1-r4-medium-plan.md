## Paper Question

Can Dialga's prefix-r4 result survive a 32x training-scale increase and a
16x cross-key validation-scale increase while the correct runtime topology
still beats both a deterministic wrong-topology control and a same-budget
generic AutoND/DBitNet baseline?

This is the first Dialga paper-evidence completion gate. It does not attempt to
extend the observed round boundary: the completed D3/D5/D6 diagnostics did not
establish a valid prefix-r5 surface for scale-up.

## Bound Prior Evidence

DMC1 is authorized by the completed local D1/D2 chain:

- D1 trained Runtime-E4 at `2048/class`; correct AUC was `0.958417/0.958679`,
  corrupted AUC was `0.936310/0.937817`, and no-topology was near chance.
- D2 reused each correct checkpoint and changed only the runtime relation;
  both seeds retained correct-minus-corrupted margins above `+0.033` and
  correct-minus-no-topology margins above `+0.432`.
- D4 showed that a deterministic linear baseline is already extremely strong
  on this r4 benchmark. The paper claim must therefore be a heterogeneous
  topology-routing/mechanism claim, not a claim that neural inference beats
  deterministic cryptanalysis.

The D1 gate, D1 validation, D1 results, D2 gate, D2 validation and D2 results
are launch authorities and are SHA256-bound by the launch gate.

## Preregistered Gate

Protocol validity requires the exact six-row matrix, parameter counts, data
sizes, keys, negative definition, runtime window, optimizer, cache events,
checkpoints and source-commit pin.

Each seed must independently satisfy:

```text
correct AUC >= 0.900
correct - corrupted AUC >= +0.005
correct - AutoND AUC >= +0.010
```

The `0.900` floor tests retention of the strong D1 mechanism at medium scale;
it is intentionally stricter than the generic `0.550` candidate floor. A seed
cannot be rescued by averaging.

## Claim Boundary

DMC1 is a medium-scale architecture/protocol diagnostic. It is not formal or
paper-scale evidence, not a full 16/20-round Dialga result, not an attack or
key-recovery result, not a SOTA claim, and not evidence that one shared neural
network universally handles all heterogeneous SPNs.
